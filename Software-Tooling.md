
# Software Tooling

## Playstation 4/5

[PS5NorModifier](https://github.com/TheCod3rYouTube/PS5NorModifier) by TheCod3r
- The PS5 NOR Modifier is a Windows GUI based application making it easier for people to modify the NOR file for their PlayStation 5 console. This is especially useful if you need to generate a NOR file for your console to replace a corrupt or faulty NOR.
- In addition, it has a very powerful UART interface with code translation. Support the Developer, TheCod3r [here](https://www.streamelements.com/thecod3r/tip)

## Xbox One & Series S/X

[Durango POST-Code reader via RasPi Pico ](https://github.com/xboxoneresearch/PicoDurangoPOST) by XboxOneResearch
- Read error codes from an Xbox One/Series X/S using a  [Raspberry Pi PICO](https://www.raspberrypi.com/products/raspberry-pi-pico/) 

[Xbox PostCode Serial Monitor](https://github.com/xboxoneresearch/XboxPostcodeMonitor) by XboxOneResearch
- Used in conjunction with the above reader to view and understand POST codes from Xbox Consoles.

## Nintendo Switch

[HATS](https://github.com/sthetix/HATS/releases) by sthetix
- Premade collection of useful tools for modded switches
